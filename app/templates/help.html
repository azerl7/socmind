系统概览

SOCMind 是一个面向企业安全运营场景的 AI 安全告警研判与攻击链还原系统。

核心流程：日志导入 → 规则检测 → 告警生成 → AI 研判 → 攻击链还原 → 报告输出

快速入门（5 分钟体验完整流程）
1
导入演示数据

打开「系统管理」页面，点击「一键导入演示数据」按钮。系统会自动导入 Web 日志、登录日志、WAF 日志并执行规则检测。

2
查看告警

打开「告警中心」，查看规则引擎检测到的安全告警。可按等级、类型、状态筛选，点击单条告警查看详情。

3
AI 研判

在告警详情页点击「AI研判」按钮，系统会结合 RAG 知识库调用 AI 生成研判结果（需配置 OpenAI API Key）。

4
生成攻击链

打开「攻击链」页面，填写源 IP 后点击「生成攻击链」。系统会将相关告警按时间线组织为攻击阶段。

5
生成报告

在攻击链详情页点击「生成报告」，系统会生成包含时间线、证据、处置建议的安全事件报告。

配置 AI 能力

AI 研判功能需要配置 OpenAI API Key：

  1. 打开「系统管理」
  2. 填写 API Key 和模型名称
  3. 建议模型: gpt-4o-mini
  4. 保存配置后即可使用
未配置 API Key 时，系统会自动使用降级研判（基于规则引擎结果），不会阻断流程。
