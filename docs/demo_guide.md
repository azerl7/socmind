# SOCMind 演示指南

## 快速演示流程

### 1. 初始化环境
```bash
# 初始化数据库（含种子数据）
python scripts/init_db.py

# 生成演示日志数据
python scripts/generate_demo_logs.py
```

### 2. 启动系统
```bash
python app.py
```
访问 http://localhost:5000，默认账号 admin / admin123

### 3. 导入演示数据
进入「系统配置」页面 → 点击「一键导入演示数据」
系统会自动：
- 导入 Web / 登录 / WAF / 主机 / Suricata 五类日志
- 执行规则检测生成告警
- 聚合告警并生成攻击链
- 自动发现资产

### 4. 演示场景

#### 场景一：告警分析
1. 进入「告警中心」查看告警列表
2. 点击告警查看详情（原始日志、命中规则、证据）
3. 点击「AI研判」查看 AI 分析结果
4. 使用状态按钮：确认 / 误报 / 关闭

#### 场景二：攻击链还原
1. 进入「攻击链」页面
2. 点击「生成攻击链」选择时间范围
3. 查看攻击链时间线和阶段节点
4. 点击「AI摘要」生成攻击过程描述

#### 场景三：资产关联
1. 进入「资产管理」页面
2. 点击「自动发现」从已有日志提取资产
3. 点击「构建关联」建立资产关系
4. 点击「拓扑视图」查看可视化关联图

#### 场景四：报告生成
1. 进入告警详情或攻击链详情
2. 点击「生成报告」
3. 进入「报告中心」查看/下载报告

### 5. 效果预期
- 告警 20-40 条
- 攻击链 1-2 条
- 资产 5-10 个
- 资产关联关系 10-20 条
