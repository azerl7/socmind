## 1. 系统概述

### 1.1 什么是 SOCMind？

SOCMind 是一个面向企业安全运营中心（SOC）的 **AI 安全告警研判与攻击链还原系统**。它通过接入多源安全日志，利用规则引擎进行告警检测，再结合 RAG 安全知识库与大模型 API，完成从告警发现、智能研判、攻击链还原到安全报告生成的全流程。

### 1.2 核心能力

- **多源日志接入**：支持 Web 访问日志、登录日志、WAF 告警、主机安全日志、网络安全日志
- **规则检测引擎**：内置 26 条检测规则，覆盖 SQL 注入、XSS、路径穿越、命令执行、暴力破解、扫描探测等
- **AI 智能研判**：结合 RAG 知识库和大模型，自动生成告警摘要、风险等级、攻击阶段、处置建议
- **攻击链还原**：将相关告警按时间线组织为攻击链，映射到 MITRE ATT&CK 或自定义 Web 攻击链模型
- **报告生成**：一键生成 Markdown/HTML 格式的安全事件分析报告
- **完整后台**：用户管理、角色权限、审计日志、系统配置

### 1.3 核心流程

```
日志导入 → 日志解析 → 规则检测 → 告警生成
                                     ↓
                              AI 研判 + RAG 知识检索
                                     ↓
                              攻击链阶段映射
                                     ↓
                              攻击链时间线生成
                                     ↓
                              安全事件报告输出
```

## 2. 快速开始

### 2.1 本地运行

```bash
# 1. 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS socmind DEFAULT CHARACTER SET utf8mb4;"

# 2. 安装依赖
pip install -r requirements.txt

# 3. 初始化（建表 + 种子数据 + 知识库）
python scripts/init_db.py --force

# 4. 生成演示日志（可选）
python scripts/generate_demo_logs.py

# 5. 启动服务
python app.py
```

### 2.2 Docker 部署

```bash
docker compose up -d
```

### 2.3 访问系统

打开浏览器访问 **http://localhost:5000**

| 账号 | 密码 | 角色 |
|------|------|------|
| admin | admin123 | 系统管理员 |

### 2.4 5 分钟快速演示

1. 登录系统（admin / admin123）
2. 打开 **系统管理** → 点击 **一键导入演示数据**
3. 打开 **告警中心** 查看检测到的告警
4. 点击任意告警 → **AI研判** 查看分析结果
5. 打开 **攻击链** → 填写源 IP → **生成攻击链**
6. 攻击链详情页查看时间线图谱
7. 点击 **生成报告** → 查看/下载安全报告

## 4. 告警中心

告警中心是系统的核心功能模块，管理所有由规则引擎生成的安全告警。

### 4.1 告警列表

告警列表以表格形式展示所有告警，支持以下功能：

#### 筛选与搜索

| 筛选条件 | 说明 |
|----------|------|
| 严重等级 | 全部/严重/高危/中危/低危 |
| 告警状态 | 新告警/处理中/已确认/误报/已关闭 |
| 攻击类型 | SQL Injection、XSS、Brute Force 等 |
| 源 IP | 按攻击来源 IP 筛选 |
| 时间范围 | 自定义开始和结束时间 |

#### 告警字段说明

| 字段 | 说明 |
|------|------|
| 告警编号 | 唯一的告警标识（如 ALERT-20260507-0001） |
| 标题 | 告警的简要描述 |
| 攻击类型 | 检测到的攻击手法分类 |
| 等级 | 严重程度（严重/高危/中危/低危） |
| 风险分 | 0-100 的综合风险评分 |
| 源 IP | 发起攻击的来源 IP 地址 |
| 状态 | 告警当前处理状态 |
| 时间 | 告警发生时间 |

#### 风险评分模型

风险分基于以下维度计算：

- **规则等级基础分**（40%）：根据命中规则的严重等级赋分
- **攻击类型权重**（20%）：不同类型的攻击有不同的权重系数
- **上下文增强**（20%）：是否有账号、资产、目标 IP 等关联信息
- **时间衰减**（20%）：较新的事件有更高评分

### 4.2 告警详情

点击告警列表中的任意告警进入详情页。详情页包含以下信息区域：

#### 基本信息

展示告警的完整字段，包括编号、标题、攻击类型、等级、风险分、源/目标 IP、关联账号、状态、时间等。

#### 规则信息

展示命中该告警的检测规则详情，包括规则编码、名称、描述和正则表达式。

#### 原始日志

展示触发该告警的原始日志内容，用于人工核查。

#### 证据列表

列出告警的关联证据，包括规则命中证据（匹配的特征内容）和原始日志证据。

#### 告警上下文时间线

以散点图展示该告警时间点前后 30 分钟内同一源 IP 的所有日志活动，帮助分析攻击者的完整活动序列。

#### AI 研判结果

调用大模型对告警进行分析后生成的结构化研判结果：

| 研判项 | 说明 |
|--------|------|
| 事件摘要 | 对告警的自然语言描述 |
| 风险等级 | AI 判断的风险等级 |
| 攻击阶段 | 告警对应的攻击链阶段 |
| 误报可能性 | 该告警可能为误报的概率（低/中/高） |
| 管理摘要 | 面向管理层的简要说明 |
| 处置步骤 | 面向技术人员的可操作处置步骤 |
| 影响范围 | 攻击可能造成的影响分析 |

> **提示**：如果尚未配置 OpenAI API Key，系统会使用降级研判模式，基于规则引擎结果生成模板化的研判结果。

#### 人工修订 AI 结果

AI 研判结果支持人工修订：

1. 在 AI 研判结果区域点击 **修订** 按钮
2. 修改摘要、风险等级、处置建议等内容
3. 填写修订说明
4. 点击 **保存修订**

修订后的结果会标记为"已修订"，并记录修订人和修订时间。

#### 分析笔记

可以在告警详情右侧添加分析笔记，用于团队协作和研判记录。笔记支持以下类型：

- **普通笔记**：自由格式的分析意见
- **状态变更记录**：系统自动记录告警状态变化

#### 告警状态流转

告警支持以下状态及流转路径：

```
新告警 (new)
  ↓
处理中 (in_progress)  ← AI 研判或手动标记
  ↓
已确认 (confirmed)    ← 确认为真实攻击
误报 (false_positive) ← 判断为误报
已关闭 (closed)       ← 处置完成
```

操作方式：在告警详情页顶部点击对应的状态按钮（确认/误报/关闭）。

### 4.3 批量操作

在告警列表中，支持批量选择告警进行状态更新：

1. 勾选需要批量处理的告警
2. 选择目标状态（确认/误报/关闭）
3. 确认操作

### 4.4 告警聚合

系统会自动将同一源 IP、同一资产、时间窗口内的多条相关告警聚合为 **安全事件**。聚合条件：

- 相同源 IP 或相同目标资产
- 时间窗口内的告警（默认 10 分钟）
- 状态为"新告警"或"处理中"的告警

聚合后的事件可以在 **安全事件** 页查看。

### 4.5 告警去重

自动去重机制会检测以下重复条件：

- 相同的命中规则
- 相同的源 IP
- 相同的攻击类型
- 5 分钟时间窗口内

重复告警会自动删除，避免告警风暴。

## 5. 安全事件

安全事件将多条相关告警聚合为统一的安全事件，便于整体研判。

### 5.1 事件列表

展示所有聚合后的安全事件，包含事件编号、标题、源 IP、严重等级、风险分、时间范围等。

### 5.2 事件详情

单个事件详情包含：

- 事件基本信息（编号、标题、等级、时间范围）
- 关联告警列表（按时间排序）
- 事件摘要（聚合后自动生成）
- 操作按钮：生成攻击链、AI 研判、生成报告

### 5.3 从事件生成攻击链

在事件详情页点击 **生成攻击链**，系统会自动：

1. 提取事件下的所有关联告警
2. 为每条告警映射攻击阶段
3. 按时间线排列各阶段节点
4. 计算链置信度和综合风险分

## 6. 日志中心

日志中心管理所有原始安全日志的导入、解析、检索。

### 6.1 支持的日志类型

| 日志类型 | 文件格式 | 说明 |
|----------|----------|------|
| Web 访问日志 | .log / .txt | Nginx/Apache combined 格式 |
| 登录日志 | .csv | 登录行为记录 |
| WAF 告警日志 | .json | Web 应用防火墙告警 |
| 主机安全日志 | .log / .txt | SSH auth.log、sudo 日志 |
| 网络安全日志 | .json | Suricata eve.json、Zeek conn.log |

### 6.2 导入日志

#### 上传文件

1. 点击 **上传文件** 按钮
2. 选择本地日志文件
3. 选择对应的日志类型（Web/登录/WAF/主机/网络）
4. 填写来源说明（可选）
5. 确认上传

支持的日志格式：

**Web 日志（Nginx combined 格式）**：
```
192.168.1.100 - - [08/May/2026:10:12:00 +0000] "GET /search?q=test HTTP/1.1" 200 1234 "-" "Mozilla/5.0"
```

**登录日志（CSV 格式）**：
```csv
time,src_ip,username,action,result
2026-05-08 10:00:00,192.168.1.100,admin,login,fail
```

**WAF 告警（JSON 格式）**：
```json
{"timestamp":"2026-05-08T10:12:00","src_ip":"192.168.1.100","attack_type":"SQL Injection","severity":"high"}
```

### 6.3 日志检索

日志检索页面支持多条件组合查询：

| 查询条件 | 说明 |
|----------|------|
| 日志类型 | web/login/waf/host/network |
| 源 IP | 按来源 IP 精确匹配 |
| 目标 IP | 按目标 IP 精确匹配 |
| 账号 | 按关联账号精确匹配 |
| 时间范围 | 开始时间 ~ 结束时间 |
| 关键词 | 在日志内容中全文搜索 |

### 6.4 导入状态

每个导入任务会有以下状态：

- **pending**：等待处理
- **running**：正在解析导入
- **success**：导入完成
- **failed**：导入失败（可查看错误信息）

## 7. 攻击链

攻击链模块将相关告警按攻击阶段组织，还原攻击者的完整攻击路径。

### 7.1 攻击链模型

系统支持两套攻击链模型：

#### Web 攻击链（内置模型）

| 阶段 | 编码 | 说明 | 示例事件 |
|------|------|------|----------|
| 扫描探测 | recon | 攻击者收集目标信息 | 高频访问、目录扫描 |
| 敏感路径访问 | sensitive_path | 攻击者探测敏感资源 | /admin、/.git、/backup |
| 漏洞尝试 | exploit_attempt | 尝试利用安全漏洞 | SQL 注入、XSS、路径穿越 |
| 异常登录 | abnormal_login | 异常登录行为 | 暴力破解、非工作时间登录 |
| 可疑行为 | suspicious_action | 可疑操作 | Webshell 访问、命令执行 |
| 敏感数据访问 | data_access | 访问或导出敏感数据 | 敏感接口调用 |

#### MITRE ATT&CK 模型

| 阶段 | 说明 |
|------|------|
| Reconnaissance 侦察 | 收集目标信息 |
| Initial Access 初始访问 | 尝试进入系统 |
| Execution 执行 | 执行恶意动作 |
| Persistence 持久化 | 维持访问 |
| Privilege Escalation 权限提升 | 提高权限 |
| Defense Evasion 防御规避 | 规避检测 |
| Credential Access 凭据访问 | 获取凭据 |
| Lateral Movement 横向移动 | 扩展到其他主机 |
| Collection 收集 | 访问敏感数据 |
| Exfiltration 数据外传 | 数据传出 |

### 7.2 生成攻击链

在攻击链页面，通过以下条件生成：

| 参数 | 说明 |
|------|------|
| 源 IP | 指定攻击者 IP（必填） |
| 目标资产 | 指定被攻击目标 |
| 时间范围 | 限定查询的时间窗口 |

生成过程：

1. 查询指定条件内的所有告警（排除误报和已关闭的）
2. 根据规则编码或攻击类型将每条告警映射到攻击阶段
3. 按阶段排序（使用 Web 攻击链的阶段顺序）
4. 计算链置信度（>=4 阶段为高置信度，>=2 为中，<2 为低）
5. 计算综合风险分（平均分和最高分的加权平均）

### 7.3 攻击链详情

攻击链详情页展示：

#### 时间线图谱

以可视化方式展示各攻击阶段节点按时间排列，用箭头连接各阶段，直观呈现攻击演进过程。

#### 节点信息

每个阶段节点包含：

- 阶段名称和阶段图标
- 时间戳
- 证据摘要
- 关联的告警列表

#### AI 攻击链摘要

点击 **AI 摘要** 按钮，大模型会根据攻击链节点生成：

- 事件总体摘要
- 攻击阶段还原
- 关键证据分析
- 攻击成功可能性判断
- 影响范围评估
- 处置优先级建议

#### 可信度评分

| 等级 | 条件 |
|------|------|
| 高 | 覆盖 4 个及以上攻击阶段 |
| 中 | 覆盖 2-3 个攻击阶段 |
| 低 | 仅覆盖 1 个攻击阶段 |

### 7.4 从攻击链生成报告

在攻击链详情页点击 **生成报告**，可选择：

- 报告模板（标准模板 / 详细模板）
- 是否启用 AI 润色

生成的报告包含完整的事件时间线、阶段分析、证据和处置建议。

## 8. 报告中心

报告中心管理所有生成的安全分析报告。

### 8.1 报告列表

展示所有已生成的报告，包含报告编号、标题、类型、生成时间等。

### 8.2 生成报告

报告可以从以下来源生成：

| 来源类型 | 说明 |
|----------|------|
| 单告警报告 | 针对单个告警的详细分析 |
| 攻击链报告 | 基于攻击链的完整事件报告 |
| 事件报告 | 基于聚合安全事件的分析报告 |

生成选项：

- **template_id**：选择报告模板
- **use_ai_polish**：启用 AI 润色（优化报告语言风格）

### 8.3 报告内容

标准报告包含以下章节：

1. **事件摘要** — 概述事件基本信息
2. **风险等级** — 综合风险评定
3. **时间线** — 事件关键时间节点
4. **攻击链分析** — 各阶段详细分析
5. **证据清单** — 支持结论的证据列表
6. **处置建议** — 可操作的技术处置步骤
7. **管理层摘要** — 面向管理层的简要说明

### 8.4 报告导出

支持以下导出方式：

- **HTML 预览**：浏览器直接查看
- **打印/PDF**：使用浏览器打印功能（Ctrl+P）导出为 PDF
- **Markdown 下载**：下载报告原始 Markdown 内容

### 8.5 报告模板

系统内置报告模板，可在知识库中自定义模板内容。报告模板使用 Markdown 格式，支持变量替换。

## 9. 资产管理

资产管理模块自动发现和维护被监控资产信息。

### 9.1 资产列表

展示所有已发现资产的信息：

| 字段 | 说明 |
|------|------|
| 资产 IP | 资产的 IP 地址 |
| 主机名 | 资产的主机名称 |
| 类型 | 主机/Web 应用/数据库/网络设备 |
| 操作系统 | 操作系统信息 |
| 部门 | 所属部门 |

知识库提供 RAG（检索增强生成）能力，辅助 AI 研判。

### 10.1 内置知识

系统预置以下安全知识文档：

| 文档 | 内容 |
|------|------|

- **删除**：移除不再需要的文档
- **搜索**：按关键词检索相关知识

3. 可用于验证 RAG 检索效果

## 14. 完整演示流程

### 14.1 场景一：Web 攻击链还原

**目标**：展示从扫描探测到漏洞尝试的完整攻击链。

**操作步骤**：

4. 点击告警 → **AI研判** 查看智能分析
5. 进入 **攻击链** → 输入 IP `192.168.1.100` → 点击 **生成攻击链**
6. 查看攻击链时间线图谱（扫描探测 → 敏感路径 → 漏洞尝试）
7. 点击 **AI 摘要** 生成攻击过程描述
8. 点击 **生成报告** → 查看完整事件报告

**预期结果**：

- 系统生成多个 Web 攻击告警
- 攻击链覆盖 3-4 个阶段
- AI 能输出完整的攻击过程描述
- 报告包含时间线和处置建议

### 14.2 场景二：账号暴力破解

**目标**：展示账号安全研判能力。

**操作步骤**：

1. 导入演示数据（同上）

3. 查看告警详情中的登录失败次数统计
4. 运行 AI 研判，查看风险等级和处置建议

**预期结果**：

- 系统生成暴力破解告警
- AI 判断风险等级为高
- 处置建议包含账号锁定、密码重置、源 IP 监控

### 14.3 场景三：综合安全事件复盘

**目标**：展示多源日志关联分析能力。

**操作步骤**：

1. 导入演示数据（包含 Web、登录、WAF、主机、网络日志）

**预期结果**：

- 攻击链覆盖多个阶段（扫描→漏洞尝试→异常登录→可疑行为）
- AI 生成管理层摘要和技术处置建议

## 15. 常见问题

### 15.1 启动后页面报 404 错误？

这是正常现象——系统会重定向到登录页。如果未登录时访问不存在的页面，会自动跳转到登录页面。登录后即可正常访问。

### 15.2 如何配置 AI 功能？

进入 **系统管理** → **AI 配置**，填写 OpenAI API Key 和模型名称后保存。推荐使用 `gpt-4o-mini` 或更高版本。如果 API Key 不可用，系统会自动降级为基于规则引擎的研判模式。

### 15.3 如何导入自己的日志？

进入 **日志中心**，点击 **上传文件**，选择符合格式要求的日志文件（Web/登录/WAF/主机/网络），上传后系统会自动解析。然后进入 **规则管理** 点击 **执行检测** 来生成告警。

### 15.4 告警太多怎么办？

- 使用 **告警聚合** 功能将相关告警合并为事件
- 配置 **告警抑制规则** 过滤已知误报
- 使用 **批量操作** 快速处理大量告警
- 合理配置告警阈值（系统管理 → 检测阈值配置）

### 15.5 攻击链不准确如何修正？

- 手动关联更多相关告警
- 重新生成攻击链（调整时间窗口或源 IP）
- 使用 **AI 摘要** 功能弥补阶段性信息
- 后续版本将支持手动增删攻击链节点

### 15.6 忘记管理员密码？

数据库中的密码使用 Werkzeug 的 `generate_password_hash` 加密存储。重置方法：

```python
# 进入 Flask shell
python -c "
from app import create_app, db
from app.models.user import User
app = create_app()
with app.app_context():
    u = User.query.filter_by(username='admin').first()
    if u:
        u.set_password('admin123')
        db.session.commit()
        print('密码已重置为 admin123')
"
```

### 15.7 如何修改数据库配置？

编辑项目根目录的 `.env` 文件：

```
DATABASE_URL=mysql+pymysql://用户名:密码@主机:端口/库名?charset=utf8mb4
```

或直接修改 `config.py` 中的默认值。

### 15.8 Docker 部署无法连接数据库？

确认 MySQL 容器启动完成后再启动 Flask 容器。Docker Compose 已配置 `depends_on` 和 `healthcheck`，会等待 MySQL 就绪。如果仍遇到问题：

```bash
docker compose logs mysql  # 查看 MySQL 日志
docker compose restart flask  # 重启 Flask 容器
```

### 15.9 系统支持 HTTPS 吗？

开发模式下仅支持 HTTP。生产环境建议使用 Nginx 反向代理配置 HTTPS，或使用 Docker 部署时在 Nginx 层面配置 SSL 证书。

### 15.10 如何更新规则？

支持两种方式：

- **在线更新**：通过 **规则管理** 页面直接编辑规则的正则表达式、等级、阶段等
- **批量导入**：将规则导出为 JSON 文件编辑后，再通过 **导入** 功能批量更新
