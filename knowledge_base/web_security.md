# Web 安全知识库

## OWASP Top 10 常见漏洞
1. 注入 (Injection)
2. 失效的身份认证
3. 敏感数据泄露
4. XML 外部实体 (XXE)
5. 失效的访问控制
6. 安全配置错误
7. XSS
8. 不安全的反序列化
9. 使用已知漏洞组件
10. 日志和监控不足

## 安全检测规则分类
- **Web 攻击**: SQLi, XSS, Path Traversal, RCE, SSRF, File Upload
- **账号安全**: 暴力破解, 撞库, 异常登录, 会话劫持
- **主机安全**: 异常进程, 文件变更, 权限提升
- **网络安全**: 端口扫描, DDoS, 中间人攻击

## 风险等级定义
- **Critical (严重)**: 可能导致远程代码执行或数据全量泄露
- **High (高危)**: 可能导致敏感数据泄露或权限提升
- **Medium (中危)**: 可能导致信息泄露或有限影响
- **Low (低危)**: 信息收集或扫描探测行为
