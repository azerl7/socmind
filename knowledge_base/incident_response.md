# 安全事件应急处置手册

## 事件响应流程
1. **准备**: 建立响应团队、准备工具
2. **检测与分析**: 确认告警、收集证据
3. **遏制**: 阻断攻击、隔离受影响系统
4. **根除**: 移除威胁、修补漏洞
5. **恢复**: 恢复正常运营
6. **复盘**: 总结经验、改进防御

## 常见告警处置建议

### SQL 注入告警
1. 确认受害接口和payload
2. 检查数据库日志确认是否执行成功
3. 临时增加 WAF 规则阻断
4. 代码层面改为参数化查询
5. 审查同源 IP 其他请求

### 暴力破解告警
1. 确认源 IP 和受影响账号
2. 临时锁定受影响账号
3. 将源 IP 加入临时黑名单
4. 通知用户修改密码
5. 检查是否有成功登录记录

### 命令执行告警
1. 立即隔离目标服务器
2. 确认执行结果
3. 检查系统用户和进程
4. 查看相关日志确定入侵路径
5. 执行全面安全审查

### XSS 告警
1. 确认注入点和 payload
2. 检查是否有用户受到影响
3. 修复输入输出过滤
4. 增加 CSP 头
5. 清除已存储的恶意脚本
