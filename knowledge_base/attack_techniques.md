# 常见攻击技术知识库

## SQL 注入 (SQL Injection)
- **描述**: 通过在输入中插入 SQL 语句，操纵后端数据库查询
- **常见特征**: UNION SELECT, OR 1=1, SLEEP(), 注释符 --, #
- **检测方式**: 参数中检测 SQL 关键字、特殊字符
- **影响**: 数据泄露、权限绕过、数据篡改
- **处置建议**: 使用参数化查询、输入过滤、WAF 规则

## XSS (跨站脚本攻击)
- **描述**: 在页面中注入恶意脚本代码
- **常见特征**: <script> 标签、事件处理器、javascript: 伪协议
- **检测方式**: 检测 HTML 标签、事件属性
- **影响**: 会话劫持、钓鱼攻击、页面篡改
- **处置建议**: 输出编码、Content-Security-Policy、输入过滤

## 路径穿越 (Path Traversal)
- **描述**: 利用路径操作符访问未授权文件
- **常见特征**: ../, ..\\, URL 编码变体
- **检测方式**: 检测路径中的目录遍历序列
- **影响**: 读取敏感文件（/etc/passwd, 配置文件）
- **处置建议**: 路径白名单、文件访问权限控制

## 命令注入 (Command Injection)
- **描述**: 在系统命令中注入恶意指令
- **常见特征**: 命令分隔符(;|&)、管道(|)、反引号、$()
- **检测方式**: 检测命令执行相关函数参数
- **影响**: 远程代码执行、服务器沦陷
- **处置建议**: 避免使用系统命令、输入严格校验

## 暴力破解 (Brute Force)
- **描述**: 尝试大量用户名/密码组合登录
- **常见特征**: 同 IP 短时间内大量登录失败
- **检测方式**: 统计登录失败频率
- **影响**: 账号被攻破、敏感数据泄露
- **处置建议**: 登录频率限制、多因素认证、IP 黑名单

## 目录扫描 (Directory Scanning)
- **描述**: 自动化工具探测 Web 目录结构
- **常见特征**: 高频访问、大量 404 响应
- **检测方式**: 检测请求频率和路径模式
- **影响**: 暴露敏感路径和文件
- **处置建议**: 敏感路径隐藏、访问认证、WAF 规则
